# О тестировании

Unit тесты пусть лежат в папке `backend` с постфиксом `_test`, например: `db_test.go`.
Нужны если разработка ведётся по TDD (то есть опциональны, см основной README.md).

Integration, System и немного Acceptance в папке `backend/test`.
Эти являются контрактом (своего рода интерфейс, формализованные требования) между бекенд разработчиками и другими участниками.
