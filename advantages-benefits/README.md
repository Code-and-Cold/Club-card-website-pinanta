# Подробное объяснение

## 1.

две секции на одной странице:

- секцию с преимуществами клуба;
- секцию с преимуществами для участника / человека, который вступает в клуб.

С помощью:

- компоненты;
- props;
- циклы рендера;
- шаблоны и стили;
- работу с данными внутри приложения.

---

## 2. Как устроен

Проект работает:

1. HTML-страница загружает JavaScript-приложение.
2. Vue создаёт приложение и вставляет его в элемент `#app`.
3. Главный компонент `App.vue` получает данные и передаёт их дочерним компонентам.
4. Дочерние компоненты выводят интерфейс на страницу.
5. Глобальные стили задают базовый внешний вид.

иерархия:

- корень приложения;
- несколько дочерних компонентов;
- общие стили и конфигурация проекта.

---

## 3. Что делает каждый файл

### 3.1 index.html

- есть контейнер `<div id="app"></div>` — именно туда Vue вставляет всё приложение;
- подключён главный JS-файл проекта через модуль.

“скелет” страницы, куда потом Vue вставляет интерфейс.

---

### 3.2 src/main.js

главный входной файл.

- импортирует Vue;
- импортирует главный компонент `App.vue`;
- импортирует общие стили из `base.css`;
- создаёт приложение и монтирует его в `#app`.

---

### 3.3 src/App.vue

главный компонент страницы.

- подключает дочерние компоненты;
- хранит данные в виде массивов;
- передаёт эти данные внутрь других компонентов.

#### блок `<script setup>`

объявлены:

- массив `advantages` — данные для секции преимуществ;
- массив `memberBenefits` — данные для секции с бонусами.

каждый объект массива содержит:

- `id` — уникальный идентификатор;
- `title` — заголовок;
- `accent` — выделенный текст;
- `text` — описание.

#### блок `<template>`

два компонента:

- `ClubAdvantages`;
- `MemberBenefits`.

они получают данные через атрибуты вроде `:items="advantages"`.

---

### 3.4 src/components/ClubAdvantages.vue

Это компонент, который отображает блок с преимуществами.

#### Что получает

принимает два параметра:

- `title` — заголовок секции;
- `items` — список карточек.

описаны через `defineProps()`.

#### Что показывает

- заголовок секции;
- набор карточек;
- для каждой карточки — заголовок, акцент и описание;
- иконку через отдельный компонент `ClubIcon.vue`.

#### Как строит список

Для каждого элемента массива используется `v-for`:

```vue
v-for="(item, index) in items"
```

#### `:key`

`key` нужен Vue для отслеживания элементов списка и корректного обновления интерфейса.

---

### 3.5 src/components/MemberBenefits.vue

блок “что ты получишь, вступив к нам”.

#### Что получает

- `titleLines` — строки заголовка;
- `items` — элементы списка.

#### Что показывает

- многострочный заголовок;
- список преимуществ;
- для каждого пункта — название и описание;
- иконку через `ClubIcon.vue`.

#### Почему массив строк

Потому что заголовок разбит на несколько строк, и каждая строка рендерится отдельно через `v-for`.

---

### 3.6 src/components/ClubIcon.vue

компонент с иконкой для уменьшения кода.

#### Что принимает

- `variant` — вариант иконки.

По умолчанию стоит `badge`.

#### Что делает

В зависимости от `variant` отображает один из двух SVG-рисунков:

- `badge` — один вид иконки;
- `cat` — другой вид иконки.

---

### 3.7 src/assets/base.css

файл глобальных стилей.

задаются:

- общий шрифт;
- цвета;
- фон страницы;
- базовые стили для текста и элементов;
- некоторые правила для `body`, `h1`, `p`, `img`, `svg`.

---

## 4. Как данные проходят

Поток данных в проекте такой:

- `App.vue` содержит массивы данных.
- Эти массивы передаются в дочерние компоненты через props.
- Компоненты отображают данные на странице.
- Иконки и стили дополняют интерфейс.

Пример:

- `advantages` в `ClubAdvantages.vue`;
- `memberBenefits` в `MemberBenefits.vue`.

---

## 5. Что в проекте нет

нет сложной логики:

- нет состояния через `ref()` или `reactive()`;
- нет обработки событий;
- нет запросов к серверу;
- нет маршрутизации;
- нет API.
